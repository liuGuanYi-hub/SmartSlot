## 三、 企业级三周冲刺开发计划 (Week 1 ~ Week 3)

### 📅 第 1 周：高并发调度中枢与实时协同网关 (Concurrency & Real-time Engine)
> **核心目标**：从底层彻底消除临界区超卖隐患，引入 WebSocket 打造类似“电影院/航司选座”的全网毫秒级协同选场体验。

- **✅ Day 1: Redis + Lua 脚本原子时段抢占引擎 (已完成)**
  - 将原有的两阶段查询加锁重构为**Lua 脚本原子操作** (`slot_lock.lua` / `slot_unlock.lua`)：在单次调用内完成“时段状态检查 ➔ 锁定时段 Key ➔ 绑定用户凭据与 TTL”，杜绝并发竞态条件。
  - 引入 `LuaLockManager`，支持 Redis 离线时无缝降级为本地 Caffeine + ConcurrentHashMap 内存原子锁。
- **✅ Day 2: Redisson 延迟队列精准关单与毫秒级库存回滚 (已完成)**
  - 引入 `RedissonClient` 与 `RDelayedQueue` 精准延时队列，实现下单后 15 分钟无支付自动触发关单并释放时段锁。
  - 内置本地 JVM `DelayQueue` 容灾方案，在无外部 Redis 依赖时仍可保证秒级关单自愈。
- **✅ Day 3: Spring WebSocket 全网时段广播网关 (已完成)**
  - 搭建后端 WebSocket 服务中枢 (`SlotWebSocketHandler` + `WebSocketPushService`)，注册 `/ws/slot` 原生双向长连接通道。
  - 订单预占锁 (`LOCK`)、支付出票 (`PAY`)、取消释放 (`CANCEL`)、延时超时释放 (`TIMEOUT`) 均自动触发毫秒级全网协同事件广播。
- **✅ Day 4: 前端时段网格响应式协同渲染 (已完成)**
  - `SlotMatrix.vue` 接入 WebSocket 长连接通道，自动维护心跳保活与异常退避重连。
  - 收到他人选场广播时，对应时段格子触发**平滑流体呼吸闪烁动画 (`slot-live-flash`) 与实时变色**，并在右下角弹出协同微通知，无需手动刷新。
  - 头部工具栏加入 **实时协同状态胶囊 (`live-sync-indicator`)** 与在线人数动态监测展示。
- **✅ Day 5: 接口幂等性 Token 机制与防暴力刷单 (已完成)**
  - 引入自定义注解 `@Idempotent` 与 Spring AOP 切面 `IdempotentAspect`，结合 Redis Lua 原子消费校验，防止网络抖动与连续点击导致的重复下单扣款。
  - 前端预约抽屉 `BookingDrawer.vue` 与我的预约 `MyBookingsView.vue` 提交前自动申请幂等 Token，并在 Header 中安全附带。
- **✅ Day 6-7: 第一周全真高并发压力测试与零超卖验证 (已完成)**
  - 编写多线程瞬时高并发抢占测试 `testHighConcurrencyAntiOverselling`（30 线程同时发令冲击同一场地同一时段锁）。
  - 实测结果：**有且仅有 1 笔订单成功创建，其余 29 笔被全部原子互斥拦截拒绝，实现绝对 0 超卖**。
  - 全套 9 项单元测试与前端 Vite 生产构建 100% 一次性通过，第 1 周圆满收官！

### 📅 第 2 周：Awwwards / 21st.dev 级前端动效与交互升维 (Design & Motion Overhaul)
> **核心目标**：融合 landing.love、land-book、siteinspire 与 21st.dev，将视觉质感、微动效与触感打磨至顶尖设计奖标准。

- **Day 8: 场馆立体平面全景选区地图 (Interactive SVG Map)**
  - 设计交互式场馆俯视图组件 `VenueFloorPlan.vue`：直观渲染场馆 2D/2.5D 平面布局图。
  - 鼠标悬停区域高亮发光，点击场地无缝聚焦联动下方的时段网格，打造身临其境的选场体验。
- **Day 9: 融合 21st.dev 现代 UI 原语与物理微动效**
  - 引入卡片 3D 悬浮视差倾斜效果（跟随鼠标坐标的 Smooth Tilt Effect）。
  - 核心 CTA 按钮升级为**磁吸悬停按钮 (Magnetic Button)** 与流光边框动画（Border Glow Animation）。
  - 场馆数据指标加入数字跳动翻牌器（`NumberTicker` 平滑补间动画）。
- **Day 10: 拟物化数字核销票据卡 (Ticket Stub) 深度进化**
  - 对标航空公司登机牌与 Apple 钱包 Pass，升级票据卡视觉：加入全息防伪光带流动效果。
  - 支持动态二维码（QRCode.vue）实时渲染与 6 位荧光大字号核销码，支持一键保存长图与一键复制。
- **Day 11: 30 秒 TOTP 动态核销防伪机制**
  - 为防止会员截图泄露或二手转卖倒票，引入企业级**动态 TOTP 时效核销码**：核销码每 30 秒自动刷新，后台前台双向算法校验，彻底解决倒票防伪痛点。
- **Day 12: 暗黑 / 晨曦高雅双模主题无缝切换 (Theme System)**
  - 搭建现代 CSS 变量暗黑模式（Dark Mode），对标 Linear / Vercel 高级深色科技感。
  - 支持系统主题自适应识别与一键平滑圆形遮罩转场切换（View Transitions API）。
- **Day 13-14: 60fps 流畅度优化与前端全场景走查**
  - 全面排查 DOM 重绘与回流，启用硬件加速渲染（`transform: translateZ(0)`）。
  - 完成移动端/平板端自适应响应式深度适配。
  - **交付成果**：前端视觉与动效全面完成升级，通过 Vite 生产打包验证并推送 Git。

## 四、 本地开发与启动指南

### 1. 当前环境配置
- **数据库**：MySQL 8.0 运行于 `127.0.0.1:3306`（库名：`smart_slot`）
- **后端服务**：Spring Boot 3 监听端口 `8088`，接口文档位于 `http://localhost:8088/doc.html`
- **前端服务**：Vite 5 开发服务器监听端口 `5173`，访问入口 `http://localhost:5173`
- **测试账号**：
  - 超级管理员：`admin` / `123456`
  - 尊享会员：`user` / `123456`

### 2. 启动与停止指令
- **启动后端**：`cd smart-slot-backend && mvn spring-boot:run`
- **启动前端**：`cd smart-slot-frontend && npm run dev`
- **构建前端**：`cd smart-slot-frontend && npm run build`
- **自动化测试**：`cd smart-slot-backend && mvn test`
