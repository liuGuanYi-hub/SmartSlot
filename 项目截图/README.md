# SmartSlot 主要页面截图

> 本目录收录《SmartSlot 智能场地与时段预约系统》主要功能页面截图，共 9 张。
> 截图来源与 `SmartSlot_项目说明文档.pdf` 保持一致（从项目说明文档中无损提取）。

## 截图清单

| 序号 | 文件名 | 页面说明 | 对应课程要素 |
| --- | --- | --- | --- |
| 01 | `01-首页-场馆全息概览.png` | 首页场馆全景：2.5D 交互式场馆平面总览图、16 大特色场馆卡片墙、分类筛选与关键词搜索 | 组件化开发、分页查询 |
| 02 | `02-场馆实景详情页.png` | 场馆实景沉浸详情页：场馆大图轮播、实时运营状态、各运动分类标签切换 | 组件化开发、表单交互 |
| 03 | `03-恒温泳池场馆详情.png` | 场馆规格详情（奥体国际标准恒温泳池）：场地参数、配套硬件与智慧设施、入场须知 | 组件化开发、数据展示 |
| 04 | `04-日历时段矩阵与联动选场.png` | 日历时段矩阵看板：日期切换、场馆分类筛选、时段可用状态（可选/锁定/已抢占）、点击即锁定 | 分页插件、拦截器（限流）、缓存 |
| 05 | `05-拼场搭子大厅.png` | 拼场搭子大厅：AA 制约球拼场列表、成团进度条、状态筛选与搜索 | 分页查询、表单交互 |
| 06 | `06-拼场实时聊天室.png` | 拼场实时聊天微室：WebSocket 实时消息、快捷话术面板、在线人数 | 拦截器、缓存 |
| 07 | `07-会员领券中心.png` | 会员专属神券中心：优惠券列表、领取状态、使用规则指引 | 缓存、表单交互 |
| 08 | `08-运营管理后台数据看板.png` | 运营管理后台：累计营收/订单/用户统计卡片、近 7 天营收趋势折线柱状图、场馆预约热度环形图、AI 排期决策建议 | 组件化开发、ECharts 数据可视化 |
| 09 | `09-登录与一键演示账号.png` | 登录页：账号密码登录、一键填入演示账号（会员/店长/核销员/超管）验证 RBAC 权限 | 拦截器（JWT）、表单交互、表单校验 |
