## 二、项目简介

**SmartSlot** 是一个面向体育综合体、智能场馆与会议空间的**场地与时段预约调度平台**。系统以「日历时段矩阵」为核心交互载体，用户可直接在矩阵上点选空闲时段完成下单支付，管理员可在后台进行场地配置、订单核销与运营数据分析。

核心业务闭环：

```
浏览场馆 → 查看时段矩阵 → 锁定时段 → 提交预约 → 优惠券抵扣
   → 多渠道支付 → 电子票核销 → 拼场组队 → 运营数据看板
```

## 五、运行步骤

### 5.1 环境准备

| 依赖 | 版本要求 | 说明 |
| --- | --- | --- |
| JDK | 17 及以上 | `java -version` 验证 |
| Maven | 3.8+ | `mvn -v` 验证 |
| MySQL | 8.0 | 默认端口 3306 |
| Redis | 7.0 | 默认端口 6379，**可选**，未启动时系统自动降级 |
| Node.js | 18 及以上 | `node -v` 验证 |

### 5.2 初始化数据库

```bash
# 登录 MySQL 后执行建库脚本
mysql -u root -p < sql/init.sql
```

脚本会自动创建 `smart_slot` 数据库、13 张业务表，并写入演示场馆、演示账号等初始数据。

### 5.3 启动后端

```bash
cd backend

# 安装依赖（首次执行会下载 Maven 依赖，耗时较久）
mvn clean install -DskipTests

# 启动项目
mvn spring-boot:run
```

启动成功标志：控制台输出 `Started SmartSlotApplication in x.xxx seconds`。

- 后端服务地址：`http://localhost:8088`
- 接口文档地址：`http://localhost:8088/doc.html`

> **数据库账号密码**：默认 `root / 123456`。若不是，请修改 `src/main/resources/application.yml` 中的 `spring.datasource.username` 与 `password`，或通过环境变量 `MYSQL_USERNAME` / `MYSQL_PASSWORD` 覆盖。

### 5.4 启动前端

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

启动成功后浏览器自动打开 `http://localhost:5173`（Vite 已配置 `/api` 与 `/ws` 反向代理到后端 8088 端口）。

## 七、项目亮点

1. **Redis + Lua 原子锁防超卖**：将「时段状态检查 → 锁定 → 设置 TTL」写入单个 Lua 脚本原子执行，从底层消除高并发临界区竞态。
2. **Redisson 延迟队列精准关单**：下单后 15 分钟未支付自动取消订单并回补释放时段锁，Redis 不可用时降级为 JVM 本地 `DelayQueue`。
3. **WebSocket 全网毫秒级广播**：时段状态变更（抢占 / 支付成功 / 超时取消）实时推送到所有在线客户端，界面无缝变色，实现"影院选座"式协同体验。
4. **AOP 幂等防重**：基于用户 Token + 业务路由构建原子防重令牌，杜绝网络抖动导致的重复下单。
5. **双层缓存削峰**：Caffeine 本地热点缓存 + Redis 集中缓存，保障极端断网场景下的平滑降级。
6. **RBAC 四级角色控制**：超管 / 店长 / 核销员 / 会员，配合 `@RequiresRoles` 切面与数据脱敏工具 `DataMaskUtil`。
7. **订单异常自愈**：`OrderReconciliationTask` 定时巡检僵死订单，主动对账并补偿回补时段。
